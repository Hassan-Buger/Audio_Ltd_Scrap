# Test fixtures

**These HTML files are synthetic.** They were written to exercise each parser path
(JSON-LD, Magento-style cards, microdata/OG fallback, missing-name rejection).
They were NOT captured from audiovideo.lt, which was unreachable from the
development environment. Do not read test results as evidence about the live site.

To test against real pages, save them with `audiovideo-scraper crawl` (raw HTML lands in
`data/raw/`) and copy representative pages here, replacing the synthetic files.
