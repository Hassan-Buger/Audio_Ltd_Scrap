# Audiovideo.lt Scraper Context Pack

This pack contains six project context documents and the root `AGENTS.md` entry point.

## Installation
Copy the `context/` directory and `AGENTS.md` into the root of the new scraper repository.

## Reading order
Follow the order in `AGENTS.md`.

## Important status
These documents define the user's requirements and a proposed architecture. They do not claim that a repository has been inspected, the live target site's current markup has been verified, or the scraper has been implemented. Resolve the open questions in `context/progress-tracker.md` during reconnaissance and update the documents as decisions are confirmed.
